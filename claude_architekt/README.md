# Claude Architekt

Claude Code als dauerhafter Remote-Control-Server unter Home Assistant OS – wie eine
Claude-Code-Cloud-Sitzung, nur lokal. Fuer Code und Bauthemen in den eigenen GitHub-Repos.
Bedienung aus der Claude-App (Bereich **Code**, Sitzung „Architekt“). Bash und Internet frei,
lokales Netz gesperrt, GitHub ueber einen Proxy, der nur Pushes auf `claude/*` zulaesst
(Austausch-Repo: alle Branches und Releases). Anleitung im Reiter **Dokumentation**.
