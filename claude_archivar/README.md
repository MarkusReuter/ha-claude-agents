# Claude Archivar

Claude Code als dauerhafter Remote-Control-Server unter Home Assistant OS. Bedienung aus der
Claude-App (Bereich **Code**, Sitzung „Archivar“). Durchsucht Paperless-ngx und verbessert den
OCR-Text, indem er Originale (PDF, Bilder) selbst liest. Eigener Paperless-Benutzer ohne
Loeschrecht, keine Shell, kein Web. Einrichtung und Test im Reiter **Dokumentation**.
